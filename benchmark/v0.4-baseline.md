# Topical v0.4 retrieval baseline

Recorded 2026-08-08 using deterministic generated fixtures before and after replacing the v0.3 JSON term-array search implementation.

## Privacy boundary

All public benchmark values below come from deterministic generated corpora. No live Topical store, private topic identifiers, tags, paths, or Markdown content are included.

## Generated-corpus baseline

Command:

```bash
npm run benchmark:v0.4
```

Runtime: Node.js 20.19.0, macOS arm64. Timings are local wall-clock measurements and should be compared on the same machine/runtime. Startup includes `initialize()` plus the current full `reindex()`. Mutation replaces one file with `expectedHash` protection in a 100-document topic. Query figures are the median and p95 of 21 searches across English and accent-free French queries.

| Documents | Startup/reindex | Mutation | Query median | Query p95 | Root index | Topic indexes | Total index | Root terms | Unique terms | Repeated root terms |
| ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 100 | 21.119 ms | 15.227 ms | 8.562 ms | 10.206 ms | 83,507 B | 86,332 B | 169,839 B | 2,203 | 327 | 85.2% |
| 1,000 | 114.724 ms | 14.952 ms | 8.914 ms | 9.382 ms | 849,646 B | 879,012 B | 1,728,658 B | 22,860 | 1,220 | 94.7% |
| 10,000 | 1,061.956 ms | 39.448 ms | 18.033 ms | 18.930 ms | 8,519,738 B | 8,814,514 B | 17,334,252 B | 228,594 | 10,131 | 95.6% |

Every root term entry is also copied into a topic index in this fixture: 2,203 duplicated copies at 100 documents, 22,860 at 1,000, and 228,594 at 10,000. The generated fixtures intentionally use zero tags, proving the benchmark does not depend on classification.

## Comparison gates

Run the same command after a candidate search cache is integrated. Do not remove the legacy search path until the candidate:

- rebuilds from Markdown after missing or incompatible derived state;
- preserves all path, symlink, atomic-write, conflict, audit, deletion, and publication invariants;
- passes the English/French strict and relaxed relevance fixtures;
- returns each topic once and marks relaxed fallback explicitly;
- removes term arrays from root and topic JSON indexes; and
- records before/after startup, mutation, query, and total derived-index size at all three corpus sizes.

## v0.4 SQLite FTS5 result

Recorded 2026-08-08 on Node.js 24.14.0, macOS arm64, after integrating the schema-v2 SQLite FTS5 cache. Cold rebuild creates all JSON catalogues and the cache from Markdown. Warm startup opens and integrity-checks compatible derived state without reindexing. Query figures use the same 21 English/French samples as the legacy baseline.

| Documents | Legacy startup/reindex | FTS5 cold rebuild | FTS5 warm startup | Legacy mutation | FTS5 mutation | Legacy query median / p95 | FTS5 query median / p95 | Legacy total index | FTS5 total index |
| ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 100 | 21.119 ms | 27.407 ms | 1.173 ms | 15.227 ms | 15.643 ms | 8.562 / 10.206 ms | 0.784 / 1.078 ms | 169,839 B | 234,617 B |
| 1,000 | 114.724 ms | 126.980 ms | 2.951 ms | 14.952 ms | 17.740 ms | 8.914 / 9.382 ms | 5.322 / 6.033 ms | 1,728,658 B | 1,522,020 B |
| 10,000 | 1,061.956 ms | 1,111.006 ms | 23.564 ms | 39.448 ms | 34.033 ms | 18.033 / 18.930 ms | 7.447 / 13.153 ms | 17,334,252 B | 14,342,796 B |

The candidate removes all JSON term arrays and duplicated term copies. At 10,000 documents it reduces total derived size by 17.3%, improves mutation time by 13.7%, improves median query time by 58.7%, and makes unchanged startup approximately 45 times faster. SQLite's fixed schema overhead makes the 100-document cache larger than the legacy JSON representation; the cache becomes smaller overall at the intended larger scales. Cold rebuild remains within 4.7% of the legacy full startup/reindex at 10,000 documents and is no longer paid during an unchanged startup.

The recorded migration, safety, relevance, and performance gates pass. The production tests cover schema migration, missing/corrupt cache recovery, atomic integrity-checked rebuilds, incremental topic replacement, stale-posting removal, zero-tag operation, exact tag filters, grouped strict/relaxed behavior, English/French accent-insensitive relevance, clean snippets, non-mutating reads, and cache-path symlink rejection.
