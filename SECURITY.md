# Security Policy

## Supported versions

Security fixes are applied to the latest release and the current `main` branch.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. If that option is unavailable, open a minimal issue asking the maintainer for a private contact channel without including vulnerability details, private paths, credentials, or user notes.

Useful reports include affected versions, reproduction steps using temporary data, impact, and a suggested mitigation. Relevant issues include path traversal, symlink escapes, unauthorized reads or writes, conflict-protection bypasses, data loss, and accidental disclosure of topic content.

Please allow reasonable time for investigation and a coordinated fix before public disclosure.
